jwsync

Keep your notes, highlights, bookmarks and playlists the same on every device you use JW Library on.

Nothing is uploaded. Everything happens inside this page, on this device. Your backups are never sent anywhere, and once this page has opened it works with no internet at all.

Whose library

Each person keeps their own library and their own devices. Useful on a shared tablet, or if you help someone else with theirs.

    Add a backup

    Choose the .jwlibrary backup you made on a device. You can add several at once. A zipped copy of JW Library's own Userdata folder works too, which is what lets a Shortcut fetch a library with no tapping.
