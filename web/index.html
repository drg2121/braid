      How it works
      
    
        
      
      1. On a device where you made notes, open JW Library and go to
      Personal Study ▸ ⤒ ▸ Create Backup. Save it to Files.
        2. 
      
      2. Come back here and add it. Combining starts on its own, and checks
      itself when it finishes.
        3. 
      
      3. Save the result, then restore it on every device.
        4. 
    
      
    
      
    
      Restoring replaces what is on that device.
    That is the point — the combined file has everything — but it is why you
    restore the combined file and never one device's own backup. Keep your
    original backups until you have checked that everything is there.
